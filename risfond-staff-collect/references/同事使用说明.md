# 锐仕方达人选信息收集脚本 — 同事使用说明

## 一、这是什么
自动从 staff.risfond.com 批量收集人选联系方式（姓名/电话/职位/目前公司），生成 Excel。
每查看一位人选联系方式消耗 6 R币（已解锁过的免币）。

## 二、首次使用（一次性准备，约 10 分钟）

### 1. 装环境
需要装 Python 3.10+，然后命令行依次执行：
```
pip install playwright openpyxl
python -m playwright install chromium
```

### 2. 改配置
打开 `collect.py`，找到顶部「可配置区」，只需改一处：
```python
BASE = Path(os.environ.get("RISFOND_DIR", r"D:\hermes猎头\staff-collect"))
```
把 `D:\hermes猎头\staff-collect` 换成你自己的工作目录路径。

### 3. 跑脚本
```
python collect.py 100
```
（100 = 目标人数，可改）

## 三、每次运行流程
1. 脚本会弹出一个 Chromium 浏览器窗口
2. 你在浏览器里**登录 + 搜索出人选列表**
3. 回聊天告诉 agent「done」，agent 创建信号文件 `GO3` 后自动开始收集
   - 如果你是自己命令行跑（没有 agent），就手动在该目录新建一个名为 `GO3` 的空文件
4. 脚本自动：点人选 → 查看联系方式 → 确认(6R币) → 抓取 → 关标签 → 翻页
5. 完成后生成 `人选信息收集.xlsx`

## 四、重要提醒
- **跑之前把电脑设成不休眠**，否则睡眠会中断脚本：
  `powercfg /change standby-timeout-ac 0` 和 `powercfg /change hibernate-timeout-ac 0`
- **不要关那个 Chromium 窗口，也不要在里面手动点页面**（会跟脚本打架）
- 运行中可以正常用电脑做别的事
- 中断不丢数据：重跑会自动跳过已收集的、续跑未收集的
- 每人随机停 3~10 秒模拟真人节奏；想更快/更慢改 `SLEEP_PER_PERSON`

## 五、如果网站改版
脚本里的选择器（`#in_phonenumber` 等）是 2026-08 的版本。若网站改版导致读不到数据，需重新探路更新选择器。
